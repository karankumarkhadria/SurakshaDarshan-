# SurakshaDarshan Frontend

This folder contains the React + Vite frontend for SurakshaDarshan.

Main documentation, setup steps, deployment notes, and project explanation are available in the root [README.md](../README.md).

## Local Commands

```bash
npm install
npm run dev
```

The frontend runs on:

```text
http://localhost:5173
```

Required environment variables are listed in `.env.example`.
